# ISM 2411 - Sales Data Cleaning Copilot Project

## Overview
This repository contains a modular Python data cleaning project developed for **ISM 2411** at the Muma College of Business, University of South Florida. 

The script automates header standardization, whitespace trimming, missing value imputation, and invalid record filtering for a messy sales dataset (`sales_data_raw.csv`), exporting the production-ready result to `sales_data_clean.csv`.

## Project Structure
- `data/raw/sales_data_raw.csv`: Raw input dataset
- `data/processed/sales_data_clean.csv`: Cleaned dataset output
- `src/data_cleaning.py`: Primary Python cleaning script
- `README.md`: Project description
- `reflection.md`: Reflection on Copilot usage

## How to Run

1. Open the project folder in Thonny.
2. Run `src/data_cleaning.py` (Press `F5` in Thonny).
3. The cleaned dataset will be automatically generated at `data/processed/sales_data_clean.csv`.
